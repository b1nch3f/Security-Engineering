# OWASP Cheat Sheet Series

All 140 cheat sheets from the official OWASP Cheat Sheet Series, grouped by security domain.

## Index
- [00 — Categorized index](OWASP%20Cheat%20Sheets/00_Categorized_Index.md) — every sheet, sorted into
  16 categories, the quickest way into the set.

## Categories
1. **Authentication & Identity** — authentication patterns, MFA, passkeys, OAuth2, SAML, credential stuffing.
2. **Authorization & Access Control** — access control, IDOR, authorization testing.
3. **Sessions, Cookies & Tokens** — session lifecycle, cookie theft, JWT.
4. **Input Validation & Injection** — SQLi/NoSQLi/LDAP/XPath/OS/SSTI, SSRF, traversal, upload, deserialization.
5. **Browser & Client-Side Security** — XSS (incl. DOM), CSP, CSRF, CORS, clickjacking, frontend hardening.
6. **APIs, Protocols & Web Architecture** — REST, GraphQL, gRPC, WebSocket, webhooks, microservices.
7. **Cryptography, TLS & Secrets** — crypto storage, key/secrets management, TLS/PQC, pinning, HSTS.
8. **Data Storage, Privacy & Parsing** — databases, XML/XXE, tenant isolation, user privacy, zero trust.
9. **Cloud, Containers & Infrastructure** — cloud architecture, Docker, Kubernetes, serverless, IaC.
10. **CI/CD & Software Supply Chain** — pipelines, GitHub Actions, SBOM, dependency management, npm.
11. **AI, LLM & Agent Security** — agents, RAG, prompt injection, MCP, model ops.
12. **Language & Framework Hardening** — Java, .NET, Node, PHP, Django, Laravel, Rails, React, Next.js.
13. **Secure Design, Threat Modeling & Review** — threat modeling, attack surface, abuse cases, code review.
14. **Operations, Monitoring & Response** — logging, error handling, vulnerability disclosure, virtual patching.
15. **Platforms & Embedded Systems** — mobile, automotive, drone.
16. **General Reference** — security terminology.
